Generar clave y CSR para AFIP

Completá los datos y el sistema generará la clave privada (.key) y la solicitud de certificado (.csr) listas para presentar en AFIP. Vas a descargar un ZIP con ambos archivos.

11 dígitos, sin guiones.
Pasos después de descargar el ZIP:
  1. El ZIP contiene dos archivos. El sistema ya los guardó automáticamente en:
    {{ certs_dir }}
  2. Ingresá a ARCA con clave fiscal del titular del CUIT.
  3. Ir a Administración de Certificados Digitales → Agregar alias.
  4. Subí el archivo CUIT.csr y completá el proceso.
  5. Descargá el .crt que te entrega AFIP y guardalo en la misma carpeta:
    {{ certs_dir }}
  6. Volvé a la sección Agregar empresa y usá estas rutas:
    Certificado: {{ certs_dir }}\CUIT.crt
    Clave privada: {{ certs_dir }}\CUIT_clave.key
